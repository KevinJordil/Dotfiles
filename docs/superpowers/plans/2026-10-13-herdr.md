# herdr à la place de tmux — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Guake (touche `section`) lance herdr ; workspaces = onglets principaux, tabs = sous-onglets ; tmux, resurrect et les patchs Guake supprimés.

**Architecture:** Guake n'a plus qu'un onglet dont le shell fait `exec herdr`. herdr persiste seul layouts et cwd (`~/.config/herdr/session.json`). zsh garde l'historique par onglet principal, avec le libellé du workspace herdr pour clé.

**Tech Stack:** herdr 0.9.3, Guake, zsh, jq.

**Spec:** `docs/superpowers/specs/2026-10-13-herdr-design.md`

## Global Constraints

- Thème herdr par défaut (pas de section `[theme]`).
- Jamais de `git commit` / `git push` par l'IA : commandes données à l'utilisateur.
- Branche `herdr`.
- Historique : `~/.zsh_history.d/<libellé>`, fichiers existants repris.

### Task 1: Branche + config herdr

**Files:** Create `herdr/config.toml`

- [ ] `git checkout -b herdr`
- [ ] Écrire `herdr/config.toml` :

```toml
# herdr : onglets principaux = workspaces (sidebar), sous-onglets = tabs. Thème par défaut.
onboarding = false

[terminal]
new_cwd = "follow"  # nouveau tab/pane dans le dossier courant

[keys]
switch_tab = "alt+1..9"
switch_workspace = "ctrl+alt+1..9"

[ui]
prompt_new_tab_name = false
tab_bar_right = [{ type = "datetime" }]

[experimental]
pane_history = true  # contenu des panes conservé après redémarrage
```

- [ ] Vérifier : `XDG_CONFIG_HOME=<tmp contenant herdr/config.toml> herdr config check` → `config: ok`

### Task 2: zsh

**Files:** Create `zsh/herdr.zsh` ; Modify `zsh/zshrc:1-2` ; Delete `zsh/guake-tmux.zsh`

- [ ] Écrire `zsh/herdr.zsh` :

```zsh
# Guake : son unique onglet lance herdr (onglets principaux = workspaces, sous-onglets = tabs)
# -z $TMUX : pas de herdr dans les anciens onglets tmux tant que Guake n'a pas été relancé
[[ -n $GUAKE_TAB_UUID && -z $HERDR_ENV && -z $TMUX ]] && exec herdr

if [[ -n $HERDR_ENV ]]; then
  # Historique par onglet principal (workspace) ; il suit le renommage, le nouveau part de l'ancien
  mkdir -p ~/.zsh_history.d
  _hist_follow() {
    local n=$(herdr workspace get $HERDR_WORKSPACE_ID 2>/dev/null | jq -r '.result.workspace.label // empty')
    local f=~/.zsh_history.d/${n//\//_}
    [[ -z $n || $HISTFILE == $f ]] && return
    [[ -f $f || ! -f $HISTFILE ]] || cp $HISTFILE $f
    fc -p $f $HISTSIZE $SAVEHIST
  }
  autoload -Uz add-zsh-hook && add-zsh-hook precmd _hist_follow

  # nom <x> : renomme l'onglet principal (l'historique suit au prompt suivant)
  nom() { herdr workspace rename $HERDR_WORKSPACE_ID "$1" >/dev/null; }
fi
```

- [ ] `zsh/zshrc` lignes 1-2 → `# Guake → herdr : doit rester en tête (exec herdr avant tout le reste)` / `source ~/dotfiles/zsh/herdr.zsh`
- [ ] Vérifier : `zsh -n zsh/herdr.zsh` ; chemin JSON de `herdr workspace get` contrôlé sur la sortie réelle.

### Task 5: Reprise des sets tmux (hors dépôt, une fois)

**Files:** scratchpad `import-tmux.sh`

- [ ] Script : lit `~/.local/share/tmux/resurrect/last`, pour chaque set → `herdr workspace create --label <set> --cwd <cwd 1er pane>`, chaque fenêtre → `herdr tab create --label <nom fenêtre> --cwd <cwd>`, panes supplémentaires → `herdr pane split --pane <root> --direction right --cwd <cwd>`. Le tab vide créé avec le workspace est réutilisé pour la 1re fenêtre.
- [ ] Mode `--dry-run` d'abord, puis exécution par l'utilisateur après relance de Guake.

### Test manuel (utilisateur)

1. `./install.sh` puis `guake --quit; guake &`
2. Touche `section` → herdr s'affiche, sidebar à gauche.
3. Lancer `import-tmux.sh` → workspaces Divers / Firmware / OSP présents.
4. `herdr server stop`, rouvrir Guake → tout est revenu ; `history` différent selon le workspace.
